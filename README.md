## 📱 O Que Este Projeto Faz?

Este aplicativo foi desenvolvido especialmente para ser colocado no **link da bio do Instagram** da escola **CEI Rita Pinto de Sousa**. Ele permite que os pais e responsáveis realizem a solicitação de pré-matrícula escolar para o ano letivo de 2026 diretamente pelo celular, de forma rápida, intuitiva e sem burocracia.

### 🌟 Principais Recursos:
1. **Design Mobile-First (Otimizado para Instagram):**
   - Interface limpa, com cores amigáveis de educação infantil.
   - Perfeita compatibilidade com o navegador interno do Instagram (Android e iOS).
2. **Seleção Intuitiva de Turmas:**
   - **Infantil II** (2 anos)
   - **Infantil III** (3 anos)
   - **Infantil IV** (4 anos)
   - **Infantil V** (5 anos)
   - Escolha do turno (Manhã, Tarde, Integral ou Indiferente).
3. **Coleta Completa de Dados:**
   - **Dados do Aluno:** Nome completo, Data de nascimento (calcula idade automaticamente), Sexo, CPF (com máscara automática), RG ou Certidão de Nascimento e campo para cuidados de saúde/alergias.
   - **Dados dos Pais/Responsáveis:** Nome completo, Grau de parentesco, CPF, RG/Identidade, WhatsApp de contato e Telefone de recado.
   - **Endereço Residencial:** Comunidade/Bairro (Varjota), Rua e Número, Ponto de referência e Município (Amontada - CE).
4. **Integração Direta com WhatsApp `(88) 99654-5870`:**
   - Ao clicar no botão de envio, gera uma mensagem oficial padronizada com emojis e protocolo e redireciona direto para o WhatsApp da secretaria da escola.
5. **Cópia de Segurança & Exportação para Excel (Secretaria):**
   - Os dados ficam salvos na memória do aparelho caso haja perda de conexão.
   - Na parte inferior do site, há a opção de **"Consultar Cadastros Deste Aparelho"** e **"Baixar Tabela (CSV / Excel)"** para a equipe da escola gerenciar as inscrições em planilhas!

## 🚀 Como Colocar no Ar (Internet) para usar no Instagram?

Você pode publicar este site **100% de graça** em menos de 2 minutos. Escolha uma das opções abaixo:

### Opção 1: Netlify Drop (Mais Fácil - Sem Programação)
1. Acesse o site gratuito: [app.netlify.com/drop](https://app.netlify.com/drop)
2. Arraste a pasta inteira `cei-rita-pinto-pre-matricula` para a tela do navegador.
3. Em 5 segundos, o site estará no ar e fornecerá um link (Ex: `https://cei-rita-pinto-2026.netlify.app`).
4. Pronto! Basta copiar esse link e colar na Bio do Instagram.

### Opção 2: Vercel
1. Acesse [vercel.com](https://vercel.com) e crie uma conta gratuita.
2. Faça o upload da pasta do projeto ou conecte via GitHub.
3. O link estará no ar com certificado de segurança (HTTPS).

### Opção 3: GitHub Pages
1. Crie um repositório no GitHub (ex: `cei-rita-pinto-matriculas`).
2. Suba os arquivos `index.html`, `styles.css` e `script.js`.
3. Vá em **Settings > Pages** e ative o GitHub Pages na branch `main`.

## 📸 Como Adicionar o Link na Bio do Instagram

1. Abra o aplicativo do **Instagram** no perfil da escola.
2. Toque em **Editar Perfil**.
3. Toque em **Links** ou **Adicionar Link Externo**.
4. No campo **URL**, cole o link gerado (ex: o link da Netlify ou Vercel).
5. No campo **Título**, coloque: `🎒 Pré-Matrículas 2026 | Garanta a Vaga!`.
6. Salve as alterações.
